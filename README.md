# ClocSharp
## `cloc` but in C#  
Inspired by [AlDanial/cloc](https://github.com/AlDanial/cloc).  

## Building  
Written in C# using .NET 10.  
To build just run `dotnet build` in the project directory.  

## Running  
`dotnet run` or better yet `dotnet build -c Release` and adding the file to $PATH so it's available everywhere.
